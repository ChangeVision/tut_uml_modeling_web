= UML初学者向けチュートリアル: モデルを使ってソフトウェアを開発しよう（WEBアプリ版）


このリポジトリが提要しているのは、ソフトウェアの開発にモデリングツールを使う方法などについて独習するためのチュートリアルの文書、サンプルモデル、サンプルコードなどです。
モデリングツールとして、チェンジビジョンが開発・販売している link:https://astah.change-vision.com/ja/product/astah-professional.html[astah* Professional] を使っています。

== 現在の状況（仮リリース）

チュートリアルの文書は整備中です。
WEBアプリ版で追加する章（Web化の設計、データベース設計、Web実装など）は、まだ書かれていません。

一方、次のものは利用できます。

`codes/`:: WEBアプリ版のサンプルコードです。CLI版と同じ `score.rb` のクラスを使い、Sinatra と SQLite で動作します。セットアップと起動の方法は link:codes/README34.md[] を参照してください。
`docs/models/`:: モデルです。`bowling_score_web.asta` にはクラス図、ステートマシン図、ER図が含まれています。ER図からエクスポートしたSQL（`bowling_score_web.sql`）と、SQLite用にCHECK制約を加えたSQL（`bowling_score_web_sqlite.sql`）もあります。

`docs/` にある PDF や HTML は作成途中のものです。

== チュートリアルの文書の取得

PDF版やHTML版（HTMLと付随の画像等をまとめたもの）は、リリースページから取得できます。

* https://github.com/ChangeVision/tut_uml_modeling_web/releases[リリースページ]

tut_uml_modeling_web.pdf:: 電子ブックの体裁のPDF版です。
tut_uml_modeling_web.zip:: ブラウザで閲覧するHTML版です。Zipファイルを展開すると、`tut_uml_modeling_web_html` フォルダにファイルが展開されます。ウェブブラウザから `tut_uml_modeling_web_full.html` か `tut_uml_modeling_web.html` を参照します。前者は全体を1つのページとしてまとめた形式、後者は章ごとに別ページに分割した形式です。


より直近のものを参照したい場合には、このリポジトリをクローンして、リポジトリ中にある PDF や HTML ファイルを直接参照してください。
